# Experiment 10 — Student Registration Mini Project

## Aim
Build a student registration form with field validation and a registration preview.

## Concepts covered
Form, GlobalKey<FormState>, TextFormField, validators, TextEditingController, dropdowns, and SnackBar.

## Source code
- Submission copy: [`10_mini_project.dart`](./10_mini_project.dart)
- Integrated app implementation: [`lib/experiments/10_mini_project.dart`](../lib/experiments/10_mini_project.dart)

The submission copy matches the experiment-wise folder structure. The integrated implementation under `lib/experiments/` is what the CampusMate home screen launches. Keep both copies synchronized when editing.
