# Experiment 2 — Flutter Widgets and Layouts

## Aim

Build a student profile screen with reusable Flutter widgets and a structured layout.

## Concepts covered

Scaffold, AppBar, Center, ConstrainedBox, SingleChildScrollView, Column, Card, Padding, CircleAvatar, Row, and Text.

## Source code

- Submission copy: [`02_widgets_layouts.dart`](./02_widgets_layouts.dart)
- Integrated app implementation: [`lib/experiments/02_widgets_layouts.dart`](../lib/experiments/02_widgets_layouts.dart)

The submission copy is included to match the experiment-wise structure required for the lab. The integrated implementation under `lib/experiments/` is what the CampusMate home screen launches.
